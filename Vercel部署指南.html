Vercel 部署操作指南

评估系统 GitHub → Vercel + Supabase 部署全流程

GitHub 仓库 → Vercel 部署 ↔ Supabase 数据库
前提条件
代码已推送到 GitHub 仓库 tangsong1876/pingu 的 main 分支。请先在 GitHub Desktop 中完成推送。

第一步：创建 Supabase Postgres 数据库 免费 必需

Vercel 的 Serverless 函数文件系统是只读的，本地用的 SQLite 无法持久化数据，必须使用外部 Postgres 数据库。Supabase 提供免费的 Postgres 实例。

1打开 https://supabase.com，点击右上角 "Start your project"，用 GitHub 账号登录
2点击 "New Project"，填写项目名称（如 pingu-eval），设置数据库密码（务必记住），选择区域 "Southeast Asia (Singapore)" 离中国最近
3等待 1-2 分钟项目创建完成，进入项目首页
4点击左侧 "Project Settings"（齿轮图标）→ "Database"
5找到 "Connection string" 区域，选择 "URI" 格式，复制完整的连接字符串
postgresql://postgres.[项目ref]:[你的密码]@aws-0-[区域].pooler.supabase.com:6543/postgres
连接字符串格式说明
形如：postgresql://postgres:你的密码@db.xxxxx.supabase.co:5432/postgres
或者通过连接池：postgresql://postgres.xxxxx:你的密码@aws-0-ap-southeast-1.pooler.supabase.com:6543/postgres
把 [YOUR_PASSWORD] 替换为你设置的真实密码

第二步：在 Vercel 导入 GitHub 仓库

1打开 https://vercel.com，用 GitHub 账号登录
2点击 "Add New..." → "Project"
3在 "Import Git Repository" 列表中找到 tangsong1876/pingu，点击 "Import"
4先不要点 Deploy！展开 "Environment Variables" 区域，添加以下三个环境变量：
变量名 值 说明
DATABASE_URL 你在第一步复制的 Supabase 连接字符串 必需 Postgres 数据库连接
VERCEL 1 必需 标识运行在 Vercel 环境
SECRET_KEY 随意一串随机字符，如 eval-prod-secret-7a3b9c2f8e1d 必需 用于 Token 加密，不要用默认值
5确认环境变量添加完毕后，点击 "Deploy"
6等待 2-3 分钟构建完成。看到 "Congratulations" 页面即部署成功

第三步：验证部署

1在 Vercel 部署成功页面点击 "Visit" 或记录分配的域名（如 https://pingu-xxxxx.vercel.app）
2用浏览器打开该域名，应看到评估系统登录页面
3用管理员账号登录：admin / admin@2026
4首次访问会自动初始化数据库（创建表 + 种子管理员），可能稍慢（5-10秒冷启动）
后续更新代码
以后每次用 GitHub Desktop 推送代码到 main 分支，Vercel 会自动重新部署，无需手动操作。

常见问题

Q: 部署后页面显示 500 错误？

检查 Vercel 项目页面的 "Logs" 标签，查看具体错误。最常见原因是 DATABASE_URL 没设置或密码错误。

Q: 报告导出功能（PDF/Word）不工作？

报告生成依赖 matplotlib/reportlab 等重型库。如果 Vercel 提示函数体积超限，可能需要升级到 Vercel Pro 计划或精简依赖。先测试基本功能是否正常。

Q: 图表中文显示为方框？

Vercel 是 Linux 环境，没有 Windows 微软雅黑字体。图表中的中文可能无法正确渲染。这是一个已知限制，不影响核心评估功能。

Q: 和本地数据不同步？

Vercel 版本使用 Supabase Postgres 数据库，与本地 SQLite 完全独立。两套数据互不影响。如果需要迁移本地数据，需要手动导出导入。

架构说明

本次部署的架构：

  • 前端：Flask 直接返回 HTML（static/index.html + admin.html）
  • 后端：Flask app 作为 Vercel Serverless Function 运行（api/index.py 入口）
  • 数据库：Supabase Postgres（app.py 已内置 Postgres 兼容层，自动切换）
  • 文件系统：ablls_data.json / age_map.json 随函数打包部署，只读
  • 路由：所有请求通过 vercel.json rewrite 统一转发到 api/index
